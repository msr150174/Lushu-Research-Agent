# 接口契约（API Contract）

> **本文件是多机并行开发的唯一依据。任何机器不得私自变更字段名或结构。**
> 如需变更，先改本文件 + 提交 PR + 通知所有机器，再改代码。
>
> 版本：v1.0 ｜ 技术栈：Python 3.11 + FastAPI ｜ Base URL：`/api/v1`

---

## 一、通用约定

### 响应信封

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code = 0` 成功；非 0 为业务错误
- HTTP 状态码统一 200，业务错误看 `code`

### 错误码

| code | 含义 |
|---|---|
| 0 | 成功 |
| 1001 | 参数错误 |
| 2001 | 论文不存在 |
| 2002 | PDF 解析失败 |
| 2003 | **OCR 不可用** |
| 3001 | 检索无结果（→ 触发"未覆盖"话术） |
| 3002 | 置信度过低（→ 拒答） |
| 4001 | 大模型 API 失败 |
| 4002 | 索引未就绪 |

### 通用错误响应

```json
{ "code": 3001, "message": "现有资料未覆盖", "data": null }
```

> ⚠️ **`3001` 和 `3002` 必须原样返回给前端**，前端展示"现有资料未覆盖"。
> **这是路书铁律的代码化，任何机器不得绕过、不得用模型知识兜底。**

## 二、模块一：PDF 管理与解析

### `POST /api/v1/papers/upload`

上传单篇 PDF。

**Request** `multipart/form-data`
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | file | ✅ | PDF 文件 |
| `auto_index` | bool | ❌ | 是否自动建索引，默认 `true` |

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "paper_id": "p_0001",
    "parse_status": "done",
    "duplicate_check": {
      "is_duplicate": false,
      "similar_papers": [],
      "suggestion": null
    }
  }
}
```

### `POST /api/v1/papers/batch-upload`

批量上传，返回 `task_id`，轮询进度。

**Response** `{ "data": { "task_id": "t_001", "total": 5 } }`

### `GET /api/v1/papers/{paper_id}`

获取论文元数据 + 结构。

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "paper_id": "p_0001",
    "title": "Attention Is All You Need",
    "authors": [{"name": "Ashish Vaswani", "affiliation": "Google Brain"}],
    "abstract": "...",
    "arxiv_id": "1706.03762",
    "version": 7,
    "published_at": "2023-08-02",
    "page_count": 15,
    "content_hash": "a3f9c1...",
    "parse_status": "done",
    "is_scanned": false,
    "sections": [ /* 见 02-数据模型.md */ ],
    "has_references": true
  }
}
```

### `GET /api/v1/papers`

列表，支持分页与筛选。

**Query**：`page=1&size=20&keyword=&status=`

### `DELETE /api/v1/papers/{paper_id}`

删除论文及其索引。

### `POST /api/v1/papers/duplicate-check`

**语义去重专用**（官方测试用例 3.1 的核心）。

**Request**
```json
{ "paper_id": "p_0002" }
```

**Response（检测到重复）**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "is_duplicate": true,
    "similar_papers": [
      {
        "paper_id": "p_0001",
        "title": "Attention Is All You Need",
        "version": 7,
        "similarity": 0.947,
        "match_basis": "content",      // ★ 必须是 content，不是 filename
        "relation": "older_version"    // newer_version | older_version | same
      }
    ],
    "suggestion": "库中已有更新版本（v7），建议保留现有版本",
    "actions": ["overwrite", "keep", "diff"]
  }
}
```

> ⚠️ **`match_basis` 必须基于正文语义（`content`）。**
> 若实现只比对文件名或 `arxiv_id`，**视为未通过官方用例 3.1**。

### `GET /api/v1/papers/{id_a}/diff/{id_b}`

版本差异对比（官方用例的"高级表现"）。

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "summary": "v7 相对 v1 主要修订：新增多头注意力复杂度分析、补充训练细节、修正 Table 3 数据",
    "changes": [
      {"type": "modified", "section": "sec-3.2", "detail": "..."},
      {"type": "added",    "section": "appendix-A", "detail": "..."}
    ]
  }
}
```

### `POST /api/v1/papers/{paper_id}/reindex`

重建索引（用于长文档分级加载）。

## 三、模块二：抗幻觉问答（**最高优先级**）

### `POST /api/v1/chat/completions`

**流式问答**（SSE）。

**Request**
```json
{
  "session_id": "s_001",
  "question": "Attention Is All You Need 训练用了多少块 GPU、型号是什么？",
  "scope": {
    "mode": "single",                 // single | multi | all
    "paper_ids": ["p_0001"]
  },
  "options": { "stream": true, "top_k": 8 }
}
```

**Response（SSE 流）**
```
event: retrieval
data: {"chunks":[{"chunk_id":"c_01","score":0.87}], "elapsed_ms": 120}

event: token
data: {"delta":"作者使用"}

event: token
data: {"delta":" 8 块 NVIDIA P100 GPU"}

event: citation
data: {"anchor":{"anchor_id":"an_012","paper_id":"p_0001","page":7,
       "bbox":[120,340,480,392],"quote":"We trained ... on 8 NVIDIA P100 GPUs",
       "section":"sec-3.1"}}

event: guardrail
data: {"triggered":true,"type":"citation_verified","action":"pass"}

event: done
data: {"answer_id":"a_001","token_usage":312,"has_citation":true}
```

**无覆盖时（关键行为）**
```
event: guardrail
data: {"triggered":true,"type":"no_source","action":"refuse"}
event: token
data: {"delta":"现有资料未覆盖该问题。"}
event: done
data: {"answer_id":"a_002","has_citation":false,"reason":"no_source"}
```

### `GET /api/v1/chat/sessions`

会话列表。

### `POST /api/v1/chat/sessions`

新建会话。

### `GET /api/v1/chat/sessions/{id}/messages`

历史消息。

### `POST /api/v1/chat/verify-citation`

**锚点校验**（本项目特色，用于防伪造引文）。

**Request**
```json
{ "anchor_id": "an_012", "quoted_text": "We trained ... on 8 NVIDIA P100 GPUs" }
```

**Response**
```json
{ "code": 0, "method": "ok",
  "data": { "valid": true, "page": 7, "bbox": [120,340,480,392], "hash_match": true } }
```

> `code` 应为 `0`；`method` 字段请实现为 `"ok"`（历史笔误保留兼容）。

## 四、模块三：版式阅读与联动翻译

### `GET /api/v1/papers/{paper_id}/layout?page={n}`

返回单页排版信息（供前端 PDF.js 渲染 + 锚点定位）。

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "page": 7,
    "width": 612, "height": 792,
    "is_two_column": true,
    "columns": [{"x0": 54, "x1": 296}, {"x0": 316, "x1": 558}],
    "blocks": [
      {"block_id":"b_01","type":"title","bbox":[54,72,558,96],"text":"3.1 Encoder and Decoder Stacks"},
      {"block_id":"b_02","type":"formula","bbox":[54,120,558,148],"latex":"\\mathrm{Attention}(Q,K,V)=\\mathrm{softmax}(\\frac{QK^T}{\\sqrt{d_k}})V"},
      {"block_id":"b_03","type":"paragraph","bbox":[54,160,296,320],
       "text":"...", "anchor_id":"an_012"}
    ]
  }
}
```

### `GET /api/v1/papers/{paper_id}/outline`

标题树（一/二/三级）。

### `GET /api/v1/papers/{paper_id}/references`

参考文献列表（含解析出的 `[n]` 编号与目标 paper_id，用于双向跳转）。

```json
{
  "code": 0, "message": "ok",
  "data": [
    { "ref_index": 11, "raw": "Bahdanau et al. Neural machine translation...",
      "resolved_paper_id": null, "resolved_external": "huggingface.co/..." }
  ]
}
```

### `POST /api/v1/translate`

**翻译**（支持划词/整段/整篇）。

**Request**
```json
{
  "paper_id": "p_0001",
  "target_lang": "zh",
  "scope": "selection",           // selection | paragraph | section | full
  "anchor_ids": ["an_012"],
  "preserve_math": true           // ★ 公式与代码必须保留英文
}
```

**Response**
```json
{ "code": 0, "message": "ok",
  "data": { "translations": [{ "anchor_id": "an_012", "source": "...", "target": "..." }] } }
```

> ⚠️ **`preserve_math = true` 时，公式、变量名、代码片段必须保持原文**，不得翻译。

### `GET /api/v1/papers/{paper_id}/alignment?page={n}&lang_a=en&lang_b=zh`

中英对照数据（供两侧联动滚动）。

## 五、模块四：检索、追踪与推荐

### `GET /api/v1/search/arxiv?q={query}&max_results=20`

**Request Query**：`q`、`max_results`、`sort_by`（`relevance`|`submittedDate`）

### `POST /api/v1/papers/fetch-by-ref`

**智能下钻下载**（给定参考文献列表自动抓取）。

**Request**
```json
{ "references": ["Attention Is All You Need", "BERT: Pre-training of Deep Bidirectional Transformers"] }
```

### `POST /api/v1/search/track`

arXiv 动态追踪（定时任务）。

**Request**
```json
{ "keywords": ["retrieval augmented generation"], "interval": "daily", "enabled": true }
```

### `GET /api/v1/recommend?paper_id={id}&limit=10`

**个性化推荐**。要求：

- 优先推荐**附带 GitHub 开源代码**的论文（`has_github: true` 排在前面）
- 每条带 `reason`（推荐理由）
- 支持 `feedback`（点赞/踩）

```json
{
  "code": 0, "message": "ok",
  "data": [
    { "arxiv_id": "2210.03629", "title": "ReAct...", "similarity": 0.82,
      "has_github": true, "github_url": "https://github.com/ysymyth/ReAct",
      "reason": "与您库中 3 篇论文同属 Agent 方向，且提供完整复现代码",
      "citation_quality": "high" }
  ]
}
```

### `POST /api/v1/recommend/feedback`

`{ "paper_id": "...", "action": "like" | "dislike" }`

## 六、模块五：引用图谱与综述

### `POST /api/v1/graph/build`

**构建局域引用图谱**（针对批量文献，如 20 篇）。

**Request** `{ "paper_ids": ["p_0001", "p_0002", "..."] }`

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "graph_id": "g_001",
    "nodes": [
      { "id": "p_0001", "label": "Attention Is All You Need", "year": 2017,
        "role": "keystone", "pagerank": 0.182, "in_degree": 12, "out_degree": 3,
        "cluster": "transformer" }
    ],
    "edges": [
      { "source": "p_0002", "target": "p_0001", "weight": 1, "citation_quality": "substantive" }
    ],
    "metrics": { "node_count": 20, "edge_count": 47, "keystone_papers": ["p_0001", "p_0002"] }
  }
}
```

> `role` 取值：`keystone`（基石论文）/ `peripheral`（边缘衍生）/ `normal`
> `citation_quality`：`substantive`（实质引用）/ `perfunctory`（应付式引用，**应被过滤**）

### `GET /api/v1/graph/{graph_id}`

读取已构建的图谱。

### `POST /api/v1/graph/{graph_id}/summary`

**自动生成领域综述**。

```json
{ "code": 0, "message": "ok",
  "data": { "summary": "...", "topics": ["多头注意力","位置编码"], "evolution": "..." } }
```

### `POST /api/v1/graph/{graph_id}/future-work`

**Future Work 去重与前沿探索**。

```json
{
  "code": 0, "message": "ok",
  "data": {
    "directions": [
      { "idea": "降低自注意力复杂度至线性",
        "status": "solved",                // solved | partially_solved | open
        "solved_by": ["p_0015"],
        "reason": "已有 Linformer / Performer 等后续工作解决" },
      { "idea": "跨模态统一注意力", "status": "open", "solved_by": [], "reason": "..." }
    ]
  }
}
```

> ⚠️ **必须能自动排除已被后续论文解决的旧 idea**（`status: solved`）。这是评分里明写的考察点。

## 七、模块六：写作辅助与可视化

### `POST /api/v1/write/outline`

根据 idea 生成论文框架（**References 必须真实无幻觉**）。

**Request** `{ "idea": "面向长文档的层级检索增强", "paper_ids": ["p_0001"] }`

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "abstract": "...",
    "sections": [
      { "title": "Introduction", "content": "...", "citations": ["an_012"] }
    ],
    "references": [
      { "raw": "...", "verified": true, "anchor_id": "an_012", "paper_id": "p_0001" }
    ],
    "unverifiable_references": []
  }
}
```

> ⚠️ **`verified: false` 的引用必须放进 `unverifiable_references` 并显式标注**，不得伪装成已核实。

### `POST /api/v1/write/diagram`

生成拓扑图脚本。

**Request** `{ "type": "mermaid", "description": "...", "paper_ids": [] }`
**type 取值**：`tikz` | `graphviz` | `mermaid` | `matplotlib`

**Response** `{ "data": { "code": "...", "language": "mermaid" } }`

### `POST /api/v1/viz/from-csv`

上传 CSV → 生成图表 + Figure Caption。

**Request** `multipart/form-data`：`file`（CSV）、`chart_type`（`line`|`bar`|`radar3d`|`table`）

**Response**
```json
{
  "code": 0, "message": "ok",
  "data": {
    "chart_spec": { /* ECharts option */ },
    "caption": "图 1. 随模型规模增大，BLEU 分数呈对数增长趋势（r=0.93）",
    "table": { "columns": [], "rows": [] }
  }
}
```

> Caption 必须**提炼出核心趋势结论**，不能只写"这是一张折线图"。

### `POST /api/v1/translate/academic`

中文学术文本 → 学术英文。

## 十、优先级定义

| 级别 | 含义 | 要求 |
|---|---|---|
| **P0** | 生死线 | 不做完等于没交，官方用例跑不通 |
| P1 | 拿分项 | 直接影响 35% 与 25% 评分 |
| P2 | 锦上添花 | 有余力再做，或用"已预留接口"交代 |

> **三天策略**：P0 全做完（约 10 个接口），P1 尽量做，P2 写进文档说"已设计未联调"。
