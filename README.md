## 一、作品定位

科研阅读链条长期断裂在四个地方：

1. **文献版本混乱** —— 同一篇论文 v1 / v7 反复入库，靠文件名判重会把同一篇的不同版本当成两篇
2. **问答幻觉** —— 通用大模型能流畅回答「用了几块 GPU」，但给不出原文位置，翻到那一页却发现没有
3. **阅读与推理割裂** —— PDF 阅读器、翻译、笔记、图谱、写作各是各的工具
4. **创新点发现困难** —— 想找「还没被解决的旧 idea」，只能靠人海式泛读

本作品面向"检索 → 解析 → 阅读 → 对比 → 图谱洞察 → 写作"的完整科研链条，
核心命题是**如何在开放域问答中保证事实确定性**。

## 四、核心设计：溯源锚点

这是本作品抗幻觉的机制内核。任何一条引用，都必须能被机器在 50ms 内验证真伪。

```
{
  "anchor_id": "an_012",
  "paper_id": "p_0001",
  "section_id": "sec-3.1",
  "block_type": "paragraph",
  "text_sha256": "...",
  "page": 7,
  "bbox": [x0, y0, x1, y1],
  "source_level": "original"
}
```

校验流程：取 `text_sha256` → 对 `quoted_text` 重新算哈希 → 比对 → 一致则 `valid`，否则标记 `unverifiable`。

检索不到时输出「现有资料未覆盖该问题」，**不用模型内建知识兜底**。
